# Windows 10 end of support: summary

Windows 10 reached end of support on October 14, 2025. After that date Microsoft no longer provides
security updates for Windows 10 Home and Pro, except through the paid Extended Security Updates (ESU)
program. This is a short summary written for the benchmark; see Microsoft's lifecycle pages for the
authoritative text.
