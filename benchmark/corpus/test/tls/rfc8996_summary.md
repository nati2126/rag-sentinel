# RFC 8996 (March 2021): Deprecating TLS 1.0 and TLS 1.1 - summary

This is a paraphrased summary prepared for the VersionConflict benchmark; consult RFC 8996 for the authoritative text.

RFC 8996 formally deprecates TLS 1.0 and TLS 1.1. Implementations must not negotiate TLS 1.0 or TLS 1.1. The same deprecation applies to DTLS 1.0. Applications should use TLS 1.2 or TLS 1.3 instead.
