# Python 3.12: distutils removed - summary

This is a paraphrased summary prepared for the VersionConflict benchmark; consult the official Python documentation for the authoritative text.

Python 3.12 was released in October 2023. The distutils package has been removed from the standard library in Python 3.12, completing the deprecation announced in PEP 632. Third-party projects can use setuptools, which provides a compatible replacement.
