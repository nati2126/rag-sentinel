# Python 3.10: distutils deprecated - summary

This is a paraphrased summary prepared for the VersionConflict benchmark; consult the official Python documentation and PEP 632 for the authoritative text.

Python 3.10 was released in October 2021. The distutils package is deprecated in Python 3.10 (PEP 632) and is scheduled for removal in Python 3.12. Projects should migrate to setuptools or other modern packaging tools.
